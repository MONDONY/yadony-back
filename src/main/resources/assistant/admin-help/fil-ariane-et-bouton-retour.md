## À quoi ça sert

En haut de chaque page, la barre du haut vous dit où vous êtes et vous aide à revenir en arrière sans perdre votre travail.

- Le **fil d'Ariane** est la petite ligne grise au-dessus du titre, par exemple « Accueil › Comptes › Utilisateurs ».
- Le **titre** de la page s'affiche en gros dessous, suivi d'un sous-titre gris sur les grands écrans (par exemple « Audit » puis « Journal des actions sensibles »).
- Le **bouton Retour**, une flèche vers la gauche, apparaît à gauche du titre sur les pages de détail.

## Lire le fil d'Ariane

Le fil d'Ariane suit toujours le même ordre : **Accueil**, puis le domaine du menu (par exemple **Comptes**, **Argent**, **Système**), puis la page. Sur une page de détail, comme la fiche d'un utilisateur, il ajoute un dernier élément, souvent le nom de la personne.

- Les éléments soulignés au survol sont cliquables : **Accueil** et, sur une page de détail, le nom de la page de liste.
- Le nom du domaine n'est pas cliquable : un domaine n'a pas de page à lui.
- Le dernier élément, en gras, est la page que vous regardez.

Il n'y a pas de fil d'Ariane sur l'accueil ni sur les pages hors menu (connexion, changement de mot de passe).

Sur un écran étroit, seuls les deux derniers éléments restent visibles.

## Utiliser le bouton Retour

1. Ouvrez une page de détail, par exemple la fiche d'un utilisateur depuis la liste **Utilisateurs**.
2. Cliquez sur la flèche **Retour** à gauche du titre.
3. Vous revenez à l'écran précédent de la console avec vos filtres et vos onglets tels que vous les aviez laissés.

Si vous êtes arrivé directement sur la page de détail (lien reçu par un collègue, onglet rouvert), il n'y a pas d'écran précédent dans la console : le bouton Retour ouvre alors la liste à laquelle appartient la page.

## Bon à savoir

> **Bon à savoir :** le bouton Retour n'apparaît pas sur les pages de premier niveau, comme la liste des Colis ou la page Paramètres. Utilisez le menu de gauche pour changer de page. Voir [Se repérer dans le menu de gauche](/aide/se-reperer-dans-le-menu).

> **Bon à savoir :** le titre de l'onglet du navigateur affiche entre parenthèses le nombre de notifications non lues, par exemple « (3) Yadony ADMIN ». Vous voyez ainsi les nouveautés même depuis un autre onglet.
