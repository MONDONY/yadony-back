## À quoi ça sert

Pour répondre à un utilisateur, le ticket doit d'abord vous être assigné : un seul agent s'occupe d'un ticket à la fois, ce qui évite les doubles réponses. Ensuite, vous écrivez votre message, avec si besoin une réponse type et des images.

## Étapes

### 1. Vous assigner le ticket

1. Ouvrez [Support](/support) et cliquez sur le ticket dans la file (onglet **Non assignés** pour les tickets libres).
2. Sous la conversation, cliquez sur **M'assigner ce ticket**. Le même bouton existe à droite, dans le bloc **Actions**.
3. Le badge **Assigné à moi** apparaît et la zone de réponse s'ouvre.

Si le ticket est déjà pris par un collègue, la console affiche « Ce ticket est assigné à un collègue : reprenez-le pour répondre. » Voir [Résoudre ou reprendre un ticket](/aide/support-resoudre-ticket).

### 2. Écrire et envoyer la réponse

1. Écrivez votre message dans la zone **Votre réponse…**.
2. Pour gagner du temps, cliquez sur une **Réponse type** au-dessus de la zone (par exemple **Demande de précisions**, **Suivi du colis**, **Pris en charge**). Son texte s'ajoute à la suite de ce que vous avez déjà écrit ; vous pouvez le modifier avant l'envoi.
3. Pour joindre une image, cliquez sur le bouton **+** (Ajouter une image) et choisissez le fichier. Une vignette apparaît ; la croix la retire.
4. Cliquez sur **Répondre**. Raccourci : Ctrl + Entrée (Cmd + Entrée sur Mac).

Le message part dans la conversation de l'utilisateur, dans l'app. Le ticket passe dans le groupe **En attente de l'utilisateur**.

## Comprendre ce que vous voyez

- Les messages sont regroupés par jour. Ceux de l'utilisateur sont à gauche, ceux du support (marqués **Support**) à droite, avec l'heure.
- Une pastille rouge **Sans réponse depuis ...** signale un ticket à répondre qui attend depuis plus d'un jour.
- **Brouillon conservé** : votre texte est gardé si vous passez à un autre ticket puis revenez.
- **Réponse trop longue** : le message dépasse la longueur permise ; raccourcissez-le, sinon le bouton reste grisé.
- Le bouton **Répondre** reste grisé tant qu'il n'y a ni texte ni image, ou pendant l'envoi d'une image.
- Les images reçues ou envoyées s'affichent en vignettes ; un clic les ouvre en grand dans un nouvel onglet.

## Bon à savoir

- Vous pouvez envoyer une image seule, sans texte.
- On peut joindre jusqu'à 4 images par message. Seules les images sont acceptées.
- Les touches **1** à **9** ajoutent la réponse type correspondante, dans l'ordre affiché.
- Le lien **Gérer**, à droite des réponses types, permet de modifier la liste partagée. Voir [Gérer les réponses types du support](/aide/support-reponses-types).
- Un ticket **Résolu** n'accepte plus aucune réponse. Pour reprendre contact, ouvrez une nouvelle conversation : voir [Écrire à un utilisateur depuis le support](/aide/support-nouvelle-conversation).
- Avant de répondre, la colonne de droite vous aide : nom de la personne, identité vérifiée ou non, ancienneté, statut du compte, et liens **Voir la fiche**, **Ses colis**, **Ses paiements**.

## Qui peut le faire

Il faut le droit de gérer les tickets du support (rôles Super admin, Admin et Support). Seule la personne assignée peut répondre.
