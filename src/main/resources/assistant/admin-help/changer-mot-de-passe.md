## À quoi ça sert

L'écran **Changer le mot de passe** sert dans deux cas :

- **Première connexion** : un Super admin vous a donné un mot de passe temporaire. La console vous oblige à le remplacer par un mot de passe permanent avant d'ouvrir toute autre page.
- **Changement volontaire** : vous voulez changer votre mot de passe en cours de session.

## Étapes à la première connexion

1. Connectez-vous avec l'email et le mot de passe temporaire reçus. L'écran **Changer le mot de passe** s'ouvre de lui-même.
2. Tapez votre nouveau mot de passe dans **Nouveau mot de passe** (12 caractères minimum).
3. Retapez-le à l'identique dans **Confirmer**.
4. Cliquez sur **Enregistrer**. Vous arrivez ensuite sur la console (ou sur l'écran de double authentification si elle n'est pas encore activée).

## Étapes pour un changement volontaire

1. En bas du menu de gauche, cliquez sur le rond qui porte vos initiales : le menu **Mon compte** s'ouvre avec votre email et votre rôle.
2. Cliquez sur **Changer mon mot de passe**.
3. Tapez votre mot de passe actuel dans **Mot de passe actuel**.
4. Tapez le nouveau dans **Nouveau mot de passe**, puis à nouveau dans **Confirmer**.
5. Cliquez sur **Enregistrer**. Vous revenez sur la page d'accueil.

L'icône en forme d'œil de chaque champ affiche ou masque ce que vous tapez.

## Comprendre les messages d'erreur

- **Mot de passe actuel requis** : le premier champ est vide.
- **Mot de passe actuel incorrect** : le mot de passe actuel tapé n'est pas le bon.
- **Le mot de passe doit faire au moins 12 caractères** : choisissez un mot de passe plus long.
- **Les mots de passe ne correspondent pas** : **Nouveau mot de passe** et **Confirmer** sont différents.
- **Ta connexion date de plus de 5 minutes. Reconnecte-toi, puis change ton mot de passe tout de suite.** : par sécurité, le changement exige une connexion récente. Cliquez sur **Se reconnecter** dans le message, reconnectez-vous et refaites le changement aussitôt.
- **Session invalide, reconnecte-toi.** ou **Erreur lors du changement de mot de passe. Réessaie.** : reconnectez-vous puis recommencez.

## Bon à savoir

> **Bon à savoir :** à la première connexion, le champ **Mot de passe actuel** n'apparaît pas : vous venez de taper le mot de passe temporaire.

> **Bon à savoir :** dans la page Administrateurs, la colonne **Changement requis** indique **Oui** tant qu'un compte n'a pas remplacé son mot de passe temporaire.

> **Attention :** si vous avez oublié votre mot de passe, la page de connexion ne propose pas de lien de récupération. Demandez à un Super admin de le réinitialiser (voir [Réinitialiser le mot de passe d'un administrateur](/aide/administrateurs)).
