On the sign-in screen, choose phone, email, Google or Apple.
By phone you get a 6-digit code by text message; by email, a sign-in code (check your spam folder if it doesn't arrive).
If the code doesn't arrive, tap "Resend code". Only the latest code works: a new code cancels the previous ones. A code stays valid for 10 minutes.
For your security, codes are limited: 5 codes per 5 minutes and 10 per day for the same email address or phone number. After 5 wrong codes, wait 10 minutes before trying again.
By phone, the same number can sign in at most 3 times in 10 minutes, even with a correct code. Beyond that, wait a few minutes or sign in by email.
If you turned on a PIN, it is asked every time you open the app.
