You can change your number from your profile: Profile › ☰ › Edit profile › Contact details › Phone.
Enter the new number, then the verification code you receive by text message to confirm it.
A number is never changed without that code.

"This number already has its own Yadony account": another account uses this number. Sign in with this number, or contact support to merge your accounts. Number "being deleted": sign in with this number to cancel the deletion. A number left on a sign-up that was never finished is released as soon as you enter the right code.
