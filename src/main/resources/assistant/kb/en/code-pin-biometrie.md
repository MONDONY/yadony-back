The PIN and biometrics are set in Profile › ☰ › Settings › Security.
"PIN on launch" creates a 6-digit code asked every time you open the app, and you can change it afterwards.
"App lock" lets you unlock with biometrics or Face ID, but requires the PIN first.
"Biometrics before payment" asks for your fingerprint or Face ID before paying, if your phone supports it.
In the Session section, "Signed-in devices" lists your sessions: "Revoke" signs one out, "Sign out of all other devices" does it in one go.
