It is up to you to notify the recipient, from your WhatsApp, with a ready-made message.
As soon as the request is accepted, the "Let {name} know" tile in the "Your shipment" section (shipment details) opens on the real-time tracking link. Tap "Notify on WhatsApp": the recipient follows the parcel without creating an account.
Once the parcel is handed to the traveler, the pickup code is added to the message, and the button becomes "Send the code on WhatsApp", so the recipient has it at handover.
If the pickup code is blocked or expired, the tile offers the tracking link, not the code. Regenerate the code from the ticket's stub.
You can edit the message before sending it. "Share tracking", in the share icon of the header and in the "Options" menu, sends the same link.
If the recipient declined the parcel, the tile is gone: the "Recipient to replace" card appears in "To do".
