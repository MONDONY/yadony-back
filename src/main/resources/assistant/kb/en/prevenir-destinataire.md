It is up to you to notify the recipient, from your WhatsApp, with a ready-made message.
As soon as the request is accepted, the "Let [name] know" card in the shipment details offers the real-time tracking link: the recipient follows the parcel without creating an account.
Once the parcel is handed to the traveler, the pickup code is added to the message so the recipient has it at handover.
You can edit the message before sending it, and "Share tracking" sends the same link.
