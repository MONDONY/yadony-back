Open Profile › My benefits › Referrals to copy your code or invitation link and share it, on WhatsApp for example.
The reward unlocks when your friend's first parcel is delivered: you then choose an amount credited to your Yadony balance, or a discount code for your next shipment, valid for 6 months.
This choice is final.
The person you invite gets a gift too: as soon as they apply a sponsor's code, they receive a welcome code for 5% off their first shipment (see the "Welcome code for referred friends" article).
If you opened an invitation link, your friend's code is applied automatically after you sign up (silently if the server refuses it). Otherwise, enter your friend's referral code in Profile › My benefits › "I have a referral code".
