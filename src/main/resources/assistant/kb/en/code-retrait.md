The pickup code is a secret 6-digit code, created when the traveler scans the parcel at departure, not at acceptance. The sender then gets the "Send the pickup code" notification and sees the code in the shipment details.
The sender gives it to the recipient: "Let them know" button, WhatsApp message with tracking link, code and an invitation to install the app. A recipient with the app sees the code in the reception screen and gets "Your parcel is on its way". One without the app receives nothing from Yadony, only the sender's message.
On arrival, the traveler must not hand over the parcel without the code: the app offers no way to confirm delivery without it, and warns them in the arrival notification and on the delivery confirmation screen. The recipient gives the code to the traveler at handover, not before.
If it is blocked or expired, the sender generates a new one with "Regenerate the code" (the traveler can ask for one): 5 regenerations at most, then the button re-enables itself after a delay.
Sender and recipient are the same person: you collect the parcel yourself, keep your code; the "Let them know" step does not apply.
Not the DON-… tracking number, which identifies the parcel.
