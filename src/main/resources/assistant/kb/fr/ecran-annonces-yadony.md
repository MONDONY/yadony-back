Vous êtes sur Annonces Yadony : les nouveautés et informations envoyées par l'équipe Yadony. Un point de couleur signale une annonce non lue ; touchez-la pour lire son texte complet, elle est alors marquée comme lue. Tirez la liste vers le bas pour la rafraîchir. Si la liste est vide, aucune annonce n'a encore été publiée.
