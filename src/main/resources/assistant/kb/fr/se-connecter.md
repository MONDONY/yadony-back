Sur l'écran de connexion, choisissez le téléphone, l'email, Google ou Apple.
Par téléphone, vous recevez un code à 6 chiffres par SMS ; par email, un code de connexion (vérifiez vos spams s'il n'arrive pas).
La connexion par téléphone est réservée aux comptes qui ont déjà un numéro : pour un numéro inconnu, l'app indique que la connexion par téléphone n'est pas disponible. Pour créer un compte, choisissez l'email, Google ou Apple, puis ajoutez votre numéro depuis le profil : Moi › ☰ › Modifier le profil › Coordonnées › Téléphone.
Si le code n'arrive pas, touchez « Renvoyer le code ». Seul le dernier code reçu fonctionne : un nouveau code annule les précédents. Un code reste valable 10 minutes.
Si l'app indique que la connexion par téléphone est indisponible, l'envoi des SMS est momentanément interrompu : connectez-vous par email, Google ou Apple, qui restent disponibles.
Dans certains pays d'Afrique, la connexion par SMS peut être momentanément indisponible : utilisez votre e-mail, Google ou Apple.
Pour votre sécurité, les codes sont limités : 5 codes par tranche de 5 minutes pour une même adresse, 2 pour un même numéro (le premier code et un renvoi) ; après 10 codes dans la journée, un seul code par heure. Après 5 codes faux, attendez 10 minutes avant de réessayer.
Par téléphone, un même numéro peut se connecter 3 fois au plus en 10 minutes, même avec un bon code. Au-delà, attendez quelques minutes, ou connectez-vous par email.
Un compte qui demande des codes SMS pour plusieurs numéros différents en 24 heures est suspendu automatiquement, par sécurité. Si c'est une erreur, écrivez au support.
Si vous avez activé un code PIN, il vous est demandé à chaque ouverture de l'app.
