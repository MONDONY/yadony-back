Vous êtes sur Parrainage. Copiez votre lien ou votre code d'invitation, puis touchez « Partager » ou WhatsApp pour l'envoyer à vos proches. La récompense se débloque quand le premier colis d'un proche est livré : touchez alors « Choisir ma récompense » (crédit sur votre solde ou code de réduction). Vos filleuls et vos compteurs (« Inscrits », « 1er envoi fait », « Gagnés ») sont suivis ici. Si l'on vous a invité, touchez « Vous avez un code parrain ? Saisissez-le ».
