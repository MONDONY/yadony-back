Vous êtes sur Parrainage. Copiez votre lien ou votre code d'invitation, puis touchez « Partager » ou WhatsApp pour l'envoyer à vos proches. La récompense se débloque quand le premier colis d'un proche est livré : touchez alors « Choisir ma récompense » (crédit sur votre solde ou code de réduction). Vos filleuls et compteurs (« Inscrits », « 1er envoi fait », « Gagnés ») sont suivis ici. Un code d'un lien d'invitation s'applique tout seul ; sinon touchez « Vous avez un code parrain ? Saisissez-le » : vous recevez un code de bienvenue (jusqu'à -5 %, dans la limite des frais de service).
