Dans une conversation, touchez l'icône d'appel puis choisissez « Appel Yadony » (gratuit, sans montrer votre numéro) ou « Appel téléphone » (avec votre forfait).
Pendant l'appel, vous pouvez couper le micro, activer le haut-parleur, réduire l'appel ou raccrocher.
Si le micro est refusé, autorisez-le dans les réglages de votre téléphone.
Pour voir un appel quand le téléphone est verrouillé, autorisez l'affichage des appels sur l'écran verrouillé ; les appels manqués se règlent dans Notifications.
