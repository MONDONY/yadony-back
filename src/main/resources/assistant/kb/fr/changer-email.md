Si aucun email n'est encore renseigné, ajoutez-le depuis le profil : Moi › ☰ › Modifier le profil › Coordonnées › Email.
Saisissez l'adresse, puis le code de vérification envoyé à cet email pour la confirmer.
Une adresse déjà associée au compte ne peut pas être changée ni remplacée : elle sert à vous identifier à la connexion.
