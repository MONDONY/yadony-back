Dans certains pays, le code SMS n'arrive pas. Si votre numéro est dans l'un d'eux, l'app vous propose « Enregistrer sans vérifier » : aucun SMS n'est envoyé et le numéro est enregistré tel que vous l'avez saisi (Moi › ☰ › Modifier le profil › Coordonnées › Téléphone).
Il s'affiche alors avec le badge « Non vérifié ». Vous pouvez le corriger autant de fois que nécessaire tant qu'il reste dans un de ces pays.
Un conseiller Yadony peut contrôler votre numéro à la main : il affiche alors « Vérifié par Yadony », à ne pas confondre avec « Vérifié », qui signifie un numéro confirmé par code SMS. Si vous changez ensuite de numéro, le badge disparaît et le numéro redevient « Non vérifié ».
Un numéro déclaré sert seulement à être joint (expéditeur, voyageur ou destinataire peuvent vous appeler) et à permettre à Yadony de retrouver votre compte. Il ne sert jamais à vous connecter, ni aux paiements, versements ou remboursements : pour le mobile money, vous saisissez le numéro à utiliser au moment du paiement.
Un numéro déclaré ne rattache pas automatiquement à votre compte les colis ou invitations reçus à ce numéro : seul un numéro vérifié par SMS ou par Yadony le fait.
Le réglage « Masquer mon numéro » s'applique aussi à ce numéro.
Si votre pays accepte plus tard le SMS, vous pouvez vérifier le numéro par code : il remplace le numéro déclaré. Un numéro déjà vérifié par SMS ne peut pas être remplacé de cette façon.
