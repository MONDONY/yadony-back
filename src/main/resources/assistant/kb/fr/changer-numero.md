Le numéro se change depuis le profil : Moi › ☰ › Modifier le profil › Coordonnées › Téléphone.
Saisissez le nouveau numéro, puis le code de vérification reçu par SMS pour le confirmer.
Un numéro ne se modifie jamais sans ce code.
