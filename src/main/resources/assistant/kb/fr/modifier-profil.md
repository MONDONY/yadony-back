Le profil se modifie depuis Moi › ☰ › Modifier le profil.
Vous y renseignez votre prénom, votre nom de famille, votre présentation, votre ville et vos langues parlées.
L'email et le téléphone s'y ajoutent aussi, chacun avec un code de vérification ; une fois enregistrés, ils ne se remplacent pas depuis l'app.
Une jauge « Profil complet » montre ce qu'il reste à compléter.
