Quand vous appliquez le code parrain d'un ami, vous recevez un code promo personnel : jusqu'à -5 % sur votre envoi, dans la limite des frais de service Yadony, à usage unique, valable 6 mois.
Vous pouvez appliquer le code à l'inscription (l'écran facultatif « Code de parrainage » juste après la création du compte, que vous pouvez passer), en ouvrant un lien d'invitation, ou plus tard dans Moi › Mes avantages › Parrainages.
Votre code est votre prénom en majuscules, sans accent, limité à 10 lettres, suivi de 05 (par exemple AMINA05). Si votre prénom a moins de 2 lettres ou si ce code est déjà pris, il prend la forme YADO-XXXX. Une notification de bienvenue vous l'indique.
Saisissez-le quand vous créez votre envoi, comme n'importe quel code promo. Il est réservé à votre compte.
On ne peut être parrainé qu'une seule fois, vous ne pouvez pas utiliser votre propre code, et un code inconnu est refusé.
Votre parrain garde sa récompense : 5 € sur son solde ou un code de -5 %, quand votre premier colis est livré.
