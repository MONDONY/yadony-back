Si l'équipe Yadony vous a remis un code de recharge, ouvrez Mon portefeuille › Recharger, puis touchez « J'ai un code de recharge ».
Saisissez le code et validez : le montant s'ajoute à votre solde.
Ce crédit sert uniquement à payer les frais de service Yadony, lorsque l'expéditeur paie le voyageur en espèces : il n'est ni remboursable ni retirable.
Un code mal saisi compte comme un essai raté : au bout de 5 essais ratés en une heure, la saisie de codes est bloquée pendant une heure. Vérifiez le code (lettres, chiffres et tirets) avant de le valider.
