Ouvrez Moi › Mes avantages › Parrainages pour copier votre code ou votre lien d'invitation et le partager, par WhatsApp par exemple.
La récompense se débloque quand le premier colis de votre proche est livré : vous choisissez alors un montant crédité sur votre solde Yadony, ou un code de réduction pour votre prochain envoi, valable 6 mois.
Ce choix est définitif.
Si c'est vous qui avez été invité, saisissez le code parrain de votre ami dans Moi › Mes avantages › « J'ai un code parrain ».
