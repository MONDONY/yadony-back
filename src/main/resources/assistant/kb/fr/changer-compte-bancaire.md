Votre compte bancaire est enregistré chez Stripe, le prestataire de paiement de Yadony. Pour le changer, touchez « Changer de compte bancaire » : votre espace Stripe s'ouvre dans le navigateur, Stripe vous envoie un code par SMS ou par e-mail, puis vous modifiez l'IBAN dans les réglages des virements.
Le nouveau compte sert aux virements suivants ; un virement déjà en cours part vers l'ancien.
Si votre inscription Stripe n'est pas terminée, l'app vous propose d'abord de la finir.
Faites-le aussi après une notification « Virement bancaire échoué » : l'argent revient sur votre compte Stripe et repart au virement suivant vers le nouveau compte.
