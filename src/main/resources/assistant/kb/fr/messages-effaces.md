Les messages et les photos d'une conversation sont supprimés 3 jours après la livraison du colis.
Un bandeau l'indique dans la conversation, avec la date de suppression une fois le colis livré ; ensuite, la conversation affiche « Messages supprimés ».
Vous pouvez aussi supprimer l'un de vos messages dans les 15 minutes suivant l'envoi : l'autre personne voit « Message supprimé ».
Supprimer toute une conversation est définitif, pour vous et votre interlocuteur.
