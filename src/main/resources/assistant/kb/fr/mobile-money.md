Pour payer, choisissez votre pays, l'opérateur (seuls ceux que le voyageur accepte sont proposés) et le numéro qui paie, le vôtre ou celui d'un proche, puis validez la demande reçue (SMS avec lien ou code secret) : après l'acceptation du voyageur, vous avez 30 minutes. Yadony garde l'argent jusqu'à la livraison.
Pour recevoir, ouvrez Moi › Argent › Versement mobile money, indiquez le numéro (il peut différer de votre numéro Yadony) et cochez les réseaux acceptés.
Le mobile money est proposé pour les trajets en XOF ou XAF, et le voyageur reçoit à la livraison sur le même réseau que celui choisi par l'expéditeur.
