Si votre carte est refusée, essayez une autre carte ou contactez votre banque ; si la vérification de votre banque n'a pas abouti, réessayez.
Par mobile money, seuls les opérateurs acceptés par le voyageur sont proposés. Un SMS avec un lien à cliquer (Orange Côte d'Ivoire) ou une demande de code secret s'affiche sur le téléphone qui paie. Vous pouvez fermer l'écran : l'application suit le paiement et une notification vous confirme.
Après un refus, le motif est affiché (solde insuffisant, paiement non validé, plafond atteint, numéro inutilisable, opérateur indisponible, demande expirée) : vous pouvez « Renvoyer une demande » ou « Payer avec un autre numéro ».
Pour un colis, quand les 30 minutes sont écoulées : si une demande est encore en cours de validation chez l'opérateur, rien n'est annulé tant qu'elle n'est pas terminée. L'écran affiche « Pas encore validé » ; si vous validez, le paiement est pris en compte, et si elle est refusée, le paiement est annulé. Sans demande en cours, l'offre est annulée et vous refaites une offre, ou la discussion de prix revient à « à payer » et vous pouvez reprendre le paiement ou changer de moyen de paiement.
Si le problème persiste, contactez le support.
