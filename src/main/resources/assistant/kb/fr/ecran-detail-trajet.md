Vous êtes sur la fiche de votre trajet : son détail, puis le nombre de vues. La tuile « Demandes », toujours active, ouvre les demandes de ce trajet ; « Colis » liste les colis embarqués. Selon l'état : « Modifier », « Reporter », « Affiche », « Annuler » ou « Supprimer ». Colis récupérés, touchez « Arrivé à destination » ; les rappels de suivi (facultatifs) ouvrent aussi cet écran avec « Je pars », « Je suis arrivé », un résumé (colis, kilos, gain) et « Voir mes colis ». Puis « Prévenir les destinataires ». Si ce trajet n'est pas le vôtre, Yadony ouvre sa fiche expéditeur, avec « Faire une demande ».
