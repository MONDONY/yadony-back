Dans Mon portefeuille, touchez Recharger, puis choisissez : Mobile money, Carte bancaire, ou « J'ai un code de recharge ».
Par mobile money, cherchez votre pays dans le champ, choisissez l'opérateur (Orange Money, MTN MoMo ou Moov Money selon le pays), puis saisissez votre numéro : l'indicatif est déjà posé. Si le numéro appartient à un autre opérateur, l'application corrige l'opérateur toute seule.
Un pays affiché « Bientôt » n'accepte pas encore le mobile money : rechargez par carte bancaire ou avec un code de recharge.
Saisissez le montant de votre choix (raccourcis 1 000, 2 000, 5 000 ou 10 000 F CFA), dans les limites de l'opérateur, puis touchez Payer.
Selon l'opérateur, vous recevez un SMS avec un lien à toucher (Orange Money en Côte d'Ivoire) ou une demande de code secret sur votre téléphone. Vous avez 15 minutes pour valider.
Vous pouvez fermer l'écran : une notification confirme la recharge, ou explique l'échec. En rouvrant la recharge, l'application reprend la demande en cours. Si la validation arrive après les 15 minutes, le solde est quand même crédité.
Ce solde sert à payer les frais de service Yadony lorsque l'expéditeur paie le voyageur en espèces, pas à payer un colis.
