Le code PIN et la biométrie se règlent dans Moi › ☰ › Paramètres › Sécurité.
« Code PIN à l'ouverture » crée un code à 6 chiffres demandé à chaque ouverture de l'app, et vous pouvez le modifier ensuite.
« Verrouillage de l'app » permet de déverrouiller avec la biométrie ou Face ID, mais nécessite d'abord le code PIN.
« Biométrie avant paiement » demande votre empreinte ou Face ID avant de payer, si votre téléphone le permet.
Dans la section Session, « Appareils connectés » liste vos sessions : « Révoquer » en déconnecte une, « Déconnecter tous les autres appareils » le fait en un geste.
