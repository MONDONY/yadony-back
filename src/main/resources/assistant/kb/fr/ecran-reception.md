Vous êtes sur un colis qui vous est destiné. S'il attend votre réponse, touchez « Oui, c'est pour moi » pour le suivre et recevoir votre code de retrait, ou « Ce n'est pas pour moi ». Ensuite, l'écran montre l'étape du colis, votre code de retrait (« Copier le code ») et « Montrer le QR du colis » au voyageur. Le code est secret : donnez-le seulement au moment de la remise. Vous pouvez aussi « Écrire au voyageur » ou « Voir le suivi ».
