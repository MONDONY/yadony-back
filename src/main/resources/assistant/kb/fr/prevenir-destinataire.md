C'est à vous de prévenir le destinataire, depuis votre WhatsApp, avec un message déjà rédigé.
Dès que la demande est acceptée, la carte « Prévenir [prénom] » du détail de l'envoi propose le lien de suivi en temps réel : le destinataire suit le colis sans créer de compte.
Une fois le colis confié au voyageur, le code de retrait s'ajoute au message pour que le destinataire l'ait en main à la remise.
Vous pouvez modifier le message avant de l'envoyer, et « Partager le suivi » envoie le même lien.
