C'est à vous de prévenir le destinataire, depuis votre WhatsApp, avec un message déjà rédigé.
Dès que la demande est acceptée, la tuile « Prévenir {prénom} » de la section « Votre envoi » (détail de l'envoi) s'ouvre sur le lien de suivi en temps réel. Touchez « Prévenir sur WhatsApp » : le destinataire suit le colis sans créer de compte.
Une fois le colis confié au voyageur, le code de retrait s'ajoute au message, et le bouton devient « Envoyer le code sur WhatsApp », pour que le destinataire l'ait en main à la remise.
Si le code de retrait est bloqué ou expiré, la tuile propose le lien de suivi, pas le code. Régénérez le code depuis le talon du billet.
Vous pouvez modifier le message avant de l'envoyer. « Partager le suivi », dans l'icône de partage de l'en-tête et le menu « Options », envoie le même lien.
Si le destinataire a refusé le colis, la tuile n'est plus là : la carte « Destinataire à remplacer » apparaît dans « À traiter ».
