Vous êtes sur l'onglet Moi, qui regroupe votre compte : votre solde (« Recharger »), puis les rubriques Argent (dont « Préférences » : devise, pays, unités), Ma réputation (« Mon profil public », « Mes avis reçus »), Mes avantages (« Parrainages »), Suivi (« Mes litiges », « Mes abonnements ») et Aide (« FAQ & aide », « Contacter le support »). Le bouton Menu ☰ en haut ouvre « Modifier le profil », « Paramètres », « Télécharger mes données », « Se déconnecter » et « Supprimer mon compte ». Si la carte « Complétez votre compte » apparaît, elle liste ce qui manque.
