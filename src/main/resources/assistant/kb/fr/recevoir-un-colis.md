Si vous avez Yadony, les colis qui vous sont destinés apparaissent dans l'onglet Suivi, en mode « Suivre un colis », sous Réceptions.
Ouvrez-en un et touchez « Oui, c'est pour moi » pour le suivre et recevoir votre code de retrait, ou « Ce n'est pas pour moi » pour le retirer de votre liste.
Pas encore l'app ? Installez Yadony et inscrivez-vous avec le numéro indiqué par l'expéditeur (celui que montre la page de suivi) : le colis apparaît tout seul dans vos Réceptions et une notification vous prévient.
Votre code est secret : donnez-le au voyageur seulement au moment de la remise.
Un expéditeur peut aussi vous ajouter à ses destinataires : acceptez ou refusez sa demande dans Moi › Suivi › Expéditeurs autorisés.
